## [1.0.0] 2026-10-14

- Lists up to 256 `.EXE` files in the current directory, excluding itself under whatever name it runs as, and runs the one picked
- Up/Down moves within a page, PgUp/PgDn changes pages, Enter runs, Esc clears the screen and exits to DOS
- A `PAGE X OF Y` indicator and arrows on the frame show when there are more pages
- A program returns straight to the menu when it exits
- DOS reserves only the memory the menu needs while a program runs
